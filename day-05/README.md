# Day 05 — Лаборатория версий моделей

Приложение отправляет **один и тот же пользовательский промпт** в три модели и показывает ответы, время, токены и стоимость рядом. Это практическое сравнение «компактная бесплатная → быстрая основная → старшая» модель, а не универсальный рейтинг всех LLM.

| Роль | Модель | Провайдер | Стоимость |
| --- | --- | --- | --- |
| Слабая | [`liquid/lfm-2.5-2.6b:free`](https://openrouter.ai/liquid/lfm-2.5-2.6b%3Afree) | OpenRouter | $0 |
| Средняя | [`deepseek-v4-flash`](https://api-docs.deepseek.com/quick_start/pricing) | DeepSeek | По токенам |
| Сильная | [`deepseek-v4-pro`](https://api-docs.deepseek.com/quick_start/pricing) | DeepSeek | По токенам |

### Почему именно такая градация

- **Слабая — LFM 2.5 · 2.6B.** Бесплатная компактная модель на 2,6 млрд параметров. Она нужна как экономичная базовая точка сравнения и может хуже справляться с точными ограничениями в формулировке.
- **Средняя — DeepSeek V4 Flash.** Быстрая модель DeepSeek для повседневных задач: ожидается компромисс между качеством, скоростью и расходом.
- **Сильная — DeepSeek V4 Pro.** Старшая выбранная модель DeepSeek: ожидается более надёжное следование сложным условиям, но за большую стоимость и возможную задержку.

В sidebar можно задать общие `temperature` и `max_tokens`. По умолчанию задана только `temperature: 0`; пустое поле `max_tokens` не передаётся в API и не ограничивает длину ответа. Выбранные значения одинаково применяются ко всем трём вызовам. В запрос передаётся только единый пользовательский промпт: системные инструкции не добавляются. Для DeepSeek режим thinking принудительно выключен. Время включает задержку сети и провайдера — это практическая скорость ответа, а не аппаратный бенчмарк.

## Что измеряется

- **Время:** от начала API-вызова до получения полного ответа.
- **Токены:** входные и выходные из usage API.
- **Стоимость:** для OpenRouter free — `$0`; для DeepSeek рассчитывается по cache-hit, cache-miss и output tokens. При неполном usage стоимость не выдумывается.
- **Качество:** приложение показывает исходные ответы; их нужно сопоставить с условием задачи и оценить точность и ясность объяснения.

После запуска интерфейс показывает сводку: самую быструю модель, минимальное число выходных токенов, общую стоимость и таблицу метрик. Кнопка `i` в карточке открывает безопасный JSON фактически отправленного запроса без API-ключа.

## Пресеты задач

В окне **«Пресеты задач»** доступны три задачи для сравнения моделей.

| Пресет | Что проверять в ответе |
| --- | --- |
| Алфавитный порядок | Все слова из стихотворения выписаны и отсортированы по русскому алфавиту; в частности, «лесу» стоит перед «летом». |
| Переправа животных | Безопасный путь: перевезти собаку и морскую свинку, вернуться одному, затем перевезти кошку. |
| Запрет буквы «а» | Ровно два предложения о зимнем пейзаже; ни в одном слове нет буквы «а». |

## Ключи и запуск

Нужны Python 3.10+, DeepSeek API key и бесплатный OpenRouter API key.

```bash
cd day-05
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Добавьте в `.env`:

```text
DEEPSEEK_API_KEY=ваш_ключ_DeepSeek
OPENROUTER_API_KEY=ваш_ключ_OpenRouter
```

Ключ OpenRouter создаётся в личном кабинете без привязки карты для free-моделей. Модель может быть временно недоступна; тогда её карточка покажет понятную ошибку, а DeepSeek-результаты сохранятся.

```bash
python3 app.py
```

Откройте [http://127.0.0.1:5004](http://127.0.0.1:5004).

## Как подвести вывод

1. Нажмите **«Пресеты задач»**, выберите одну задачу, затем **«Запустить сравнение»**.
2. Покажите три карточки, метрики и JSON без ключей.
3. Сверьте ответы с колонкой «Что проверять в ответе» и кратко объясните, какая модель дала лучший баланс точности, времени, токенов и стоимости.

Ссылки: [OpenRouter free models](https://openrouter.ai/collections/free-models), [DeepSeek pricing](https://api-docs.deepseek.com/quick_start/pricing).
