# Day 02 — Контроль ответа DeepSeek

Это задание показывает, как один и тот же промпт меняется при контроле формата, длины и условия завершения ответа через DeepSeek API.

## Сценарий

1. Введите свой промпт и нажмите «Отправить без ограничений».
2. Получите обычный ответ DeepSeek.
3. Откройте меню настроек и задайте формат, `max_tokens` и `stop` sequence.
4. Нажмите «Отправить тот же промпт с настройками».

Второй запрос использует сохранённую строку первого промпта. Это гарантирует честное сравнение: меняются только настройки ответа.

## Настройки

- **Формат ответа** — свободная текстовая инструкция для модели, например «Краткий заголовок и ровно 3 маркированных пункта».
- **Длина ответа** — официальный параметр API `max_tokens`, ограничивающий число генерируемых токенов.
- **Условие завершения** — официальный параметр `stop`. По умолчанию используется `### END`; API завершает ответ до этого маркера, поэтому сам маркер не выводится в тексте.

Интерфейс показывает JSON-превью запросов без API-ключа, число выходных токенов и `finish_reason` каждого ответа.

## Подготовка

Нужны Python 3.10+ и ключ из [DeepSeek Platform](https://platform.deepseek.com/api_keys).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Откройте `.env` и добавьте ключ:

```text
DEEPSEEK_API_KEY=ваш_ключ_DeepSeek
```

Файл `.env` не попадает в Git.

## Запуск

```bash
python3 app.py
```

Откройте [http://127.0.0.1:5001](http://127.0.0.1:5001).
