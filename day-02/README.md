# Day 02 — Контроль ответа DeepSeek

Это задание показывает, как настройки формата, длины, условия завершения и thinking mode меняют ответ DeepSeek API.

## Сценарий

1. Введите свой промпт и нажмите «Отправить».
2. При необходимости откройте кнопку с шестерёнкой и задайте настройки.
3. Отправьте промпт ещё раз — блок ответа заменится новым результатом.

На странице отображается одно JSON-превью следующего запроса и один блок ответа. API-ключ в браузер не передаётся.

## Настройки

- **Формат ответа** — свободная текстовая инструкция для модели, например «Краткий заголовок и ровно 3 маркированных пункта».
- **Длина ответа** — официальный параметр API `max_tokens`, ограничивающий число генерируемых токенов.
- **Условия завершения** — официальный параметр `stop`. Кнопка `＋` добавляет новое поле для маркера; DeepSeek принимает до 16 уникальных маркеров за запрос. API завершает ответ на первом встретившемся маркере и не выводит его в тексте.
- **Thinking mode** — по умолчанию выключен, чтобы лимит токенов расходовался на видимый ответ. Его можно включить или оставить выбор DeepSeek.

Текстовые поля настроек изначально пусты и не добавляются в API-запрос. Thinking mode по умолчанию передаётся как `disabled`. После ответа интерфейс показывает число выходных токенов, `finish_reason`, статус thinking mode и число reasoning-токенов без внутреннего текста рассуждений.

## Подготовка

Нужны Python 3.10+ и ключ из [DeepSeek Platform](https://platform.deepseek.com/api_keys).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Откройте `.env` и добавьте ключ:

```text
DEEPSEEK_API_KEY=ваш_ключ_DeepSeek
```

Файл `.env` не попадает в Git.

## Запуск

```bash
python3 app.py
```

Откройте [http://127.0.0.1:5001](http://127.0.0.1:5001).
