# Day 03 — Машина сравнения стратегий

Один Flask-проект сравнивает четыре способа рассуждения на одинаковой задаче. По умолчанию используется бесплатный OpenRouter Free Router, но можно переключиться на DeepSeek. Никаких Angular, Node.js, `node_modules` или отдельного фронтенд-сервера: Python отдаёт страницу, а браузер обращается к тому же Flask API.

## Как пользоваться

1. Введите задачу или откройте **«Пресеты задач»**.
2. В правой боковой панели выберите способы рассуждения и при необходимости измените общие параметры ответа.
3. В блоке **«Провайдер и инструкции»** выберите DeepSeek либо OpenRouter и роль инструкций методов: `user prompt` соответствует исходной формулировке задания, `system prompt` переносит только методическую инструкцию в системное сообщение. По умолчанию включены **OpenRouter Free Router** и `system prompt`.
4. Нажмите **«Запустить сравнение»**. Выбранные варианты запускаются параллельно и появляются в отдельных карточках.
5. В карточке **«Автоинструкция»** сначала показан созданный моделью промпт, а ниже — ответ, полученный после его повторного использования. Нажмите `i` в готовой карточке, чтобы увидеть оба фактически отправленных JSON-запроса без API-ключа.
6. Внизу появится **«Анализ ответов»**: общие настройки текущего запуска, время каждого сценария, API-вызовы, выходные и reasoning-токены, а также причина завершения. Точность и качество объяснения сравнивайте по текстам карточек.

Sidebar можно свернуть — останется тонкая вкладка с кнопкой раскрытия. На мобильном экране она становится блоком под результатами.

## Методы и стоимость

| Метод | Поведение | API-вызовы |
| --- | --- | ---: |
| Прямой ответ | Только исходная задача в user-сообщении | 1 |
| Пошагово | Инструкция «Решай пошагово» передаётся в выбранной роли | 1 |
| Автоинструкция | Сначала создаёт самостоятельный промпт, затем использует его во втором запросе | 2 |
| Группа экспертов | Инструкция назначает аналитика, инженера и критика, затем общий вывод | 1 |

Пресет **«Все стратегии»** выполняет пять API-вызовов. Прямой вариант всегда содержит только исходную задачу в user-сообщении. По умолчанию инструкции методов передаются в `system prompt`, а сама задача остаётся user-сообщением. Переключатель `user prompt` переносит методическую инструкцию в текст задачи — это исходный учебный вариант. Настройки формата и stop sequence всегда оформляются отдельным system-сообщением.

## Провайдеры

- **DeepSeek · V4 Flash** — обычный учебный режим. Для него передаётся настройка thinking mode.
- **OpenRouter · Free Router** — режим по умолчанию для эксперимента с бесплатными моделями. Нужен отдельный `OPENROUTER_API_KEY`. Значение `openrouter/free` выбирает доступную бесплатную модель на стороне OpenRouter, поэтому модель может отличаться между запусками; карточка ответа покажет фактически выбранный slug. В поле «Модель» добавлены быстрые варианты: `minimax/minimax-m3:free` и `nvidia/nemotron-3-ultra-550b-a55b:free`; можно также вписать любой актуальный slug с суффиксом `:free`.

`max_tokens` и `stop` передаются обоим провайдерам. `thinking` — специфичный параметр DeepSeek, поэтому к OpenRouter не отправляется; это явно показано в интерфейсе и в JSON-карточке.

## Встроенные задачи и эталоны

- **Логическая:** в задаче «Четыре свечи» осталось **4 свечи**: две продолжают гореть, две погасли, но не исчезли. Это короткий вопрос на точность прочтения условия.
- **Алгоритмическая:** допустимый маршрут с минимальным временем — **A → C → D → F → G**, время **9 минут**, расход **7 единиц**.
- **Аналитическая:** базовая прибыль — **304 000 ₽**; кампания A — **316 976 ₽**; кампания B — **265 520 ₽**. Рекомендация — **кампания A**.

## Запуск

Нужны Python 3.10+ и ключ хотя бы одного провайдера. Для режима по умолчанию добавьте ключ OpenRouter; ключ DeepSeek нужен только при переключении на DeepSeek.

```bash
cd day-03
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Для режима по умолчанию:
# добавьте OPENROUTER_API_KEY в .env
# Необязательно: добавьте DEEPSEEK_API_KEY для режима DeepSeek
python3 app.py
```

Откройте [http://127.0.0.1:5002](http://127.0.0.1:5002).

## Проверка

```bash
cd day-03
```
