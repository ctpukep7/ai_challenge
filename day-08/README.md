# Day 08 — Лаборатория токенов

Учебное приложение для наблюдения за тем, как история диалога влияет на фактическое потребление токенов агентом. Python-агент хранит сессии, сообщения и метрики в SQLite; Vue показывает чат, сводку и график роста.

## Что именно считает приложение

После каждого **успешного** ответа приложение сохраняет поля, которые действительно вернул API в `usage`:

- текущий вызов: `prompt_tokens`, `completion_tokens`, `total_tokens`;
- дополнительные поля, если провайдер их прислал: cache-hit/cache-miss и `reasoning_tokens`;
- последний ответ: модель, провайдер, `finish_reason`, время и стоимость;
- вся сессия: сумма фактически обработанных токенов и стоимости всех успешных ходов, график роста и доля контекстного окна у последнего вызова.

В интерфейсе пять отдельных метрик: «Контекст последнего запроса» (`prompt_tokens`), «Вывод последнего запроса» (`completion_tokens`), «Контекст всего чата» (`total_tokens` последнего вызова: входной контекст вместе с ответом), «Суммарно обработано» (сумма `total_tokens` всех успешных вызовов) и «Суммарная стоимость».

До запроса интерфейс не рисует «точный прогноз»: токенизация зависит от модели, а источником истины остаётся ответ API. Если провайдер отклонил переполненный контекст без `usage`, интерфейс так и напишет.

Для быстрого эксперимента есть **синтетическая история**. После нескольких реальных сообщений нажмите `×2 для следующего запроса` несколько раз: история для одного будущего вызова будет повторена `×2`, `×4`, `×8` и так далее, максимум `×64`. Дубликаты не отображаются в чате и не сохраняются в SQLite; они существуют только в фактическом запросе к модели. После ответа режим автоматически сбрасывается до `×1`.

## Запуск одной командой

Нужны Python 3.11+ и Node.js 20+.

```bash
cd day-08
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm install
npm --prefix frontend install
cp .env.example .env
# впишите хотя бы один ключ в .env
npm run dev
```

Откройте [http://127.0.0.1:5174](http://127.0.0.1:5174). Команда одновременно запускает FastAPI на `5007` и Vue/Vite на `5174`; Vite безопасно проксирует `/api` в Python, поэтому ключ не попадает в браузер.

Проверки:

```bash
npm test
npm run build
```

## Три сценария для видео

1. **Короткий диалог.** Отправьте два коротких вопроса. После ответа смотрите «Контекст последнего запроса» и первый участок графика.
2. **Длинный диалог.** Откройте «Пресеты» и выберите «Наращивание контекста»: он вставит просьбу о развёрнутом объяснении на 700–900 слов с шестью разделами. Отправьте её и повторите этот сценарий несколько раз в одной сессии — новый запрос содержит всю сохранённую историю, поэтому `prompt_tokens` и накопленный график растут.
3. **Ускоренное увеличение контекста.** Сделайте несколько реальных ходов, затем нажмите `×2 для следующего запроса` 3–5 раз. Отправьте обычный вопрос: API получит повторённую историю, а карточка фактических токенов покажет реальный размер контекста. Если лимит превышен, провайдер вернёт ошибку; виртуальные повторы не попадут в SQLite.

Ускоренный сценарий может расходовать заметное количество входных токенов. Он не запускается автоматически: запрос отправляется только кнопкой «Отправить».

## Провайдеры, лимиты и цены

- Для DeepSeek V4 используется локальный каталог актуальных лимитов и тарифов, а стоимость вычисляется из фактически возвращённых токенов. В расчёте автоматически выбирается действующий peak/off-peak тариф по UTC; актуальные цифры — на [официальной странице цен DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/).
- Для OpenRouter сервер читает лимит контекста, максимальный output и каталог цен через [Models API](https://openrouter.ai/docs/guides/overview/models). В настройках доступны только актуальные бесплатные текстовые модели. Список упорядочен от меньшего размера контекста к большему; `usage.cost`, если он возвращён, имеет приоритет над каталогом.
- Алиас `openrouter/free` не обещает конкретную модель до ответа. Поэтому до ответа лимит и цена отображаются как неизвестные; после ответа лаборатория использует идентификатор фактически выбранной модели.

Справка о значениях `usage` и лимитах: [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/), [OpenRouter Usage Accounting](https://openrouter.ai/docs/cookbook/administration/usage-accounting).
