# Данные и границы поддержки

Day33 — учебная демонстрация. Все пользователи и тикеты в JSON вымышленные.
MCP-инструменты читают записи и связанного с тикетом пользователя.
Они не сбрасывают пароли, не меняют токены и не отправляют ответы клиентам.

Поддержка использует выбранный тикет и справку, чтобы предложить следующий
шаг. Она не выполняет удалённую диагностику компьютера пользователя.
При отсутствии подтверждений причина остаётся предположением.

Для нового тикета начинается отдельная беседа. Сообщения хранятся только
в памяти вкладки. DeepSeek получает вопрос, выбранные фрагменты справки
и вымышленные сведения выбранного тикета.

Нельзя сообщать ассистенту настоящие API-ключи, токены доступа, приватные
сертификаты и пароли. Для диагностики достаточно безопасного текста ошибки,
номера дня, шага воспроизведения и обезличенных технических сведений.
