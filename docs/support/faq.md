# FAQ поддержки AI Challenge

## Что такое AI Challenge

Это набор учебных приложений по дням. У каждого дня своя инструкция и адрес.
Для помощи сообщите номер дня, действие и текст ошибки без секретов.

## Почему не работает авторизация Day30

Day30 требует токен доступа в формате Bearer для всех маршрутов `/api/`.
Экран входа сам по себе открывается без токена. Наличие страницы не означает,
что авторизация прошла или модель уже ответила.

HTTP401 означает отсутствие подходящего токена доступа. Это не доказательство
неисправности Ollama. Возьмите действующий токен у владельца сервиса и введите
его на экране входа. Не отправляйте токен в тикет или в чат поддержки.
Не вводите вместо токена Day30 API-ключ DeepSeek.

HTTP429 означает ограничение частоты. Дождитесь времени из Retry-After.
Повторные попытки подряд не исправляют ограничение.

## Браузер сообщает об ошибке сертификата

Day30 использует локальный самоподписанный сертификат. Устройство должно
доверять сертификату владельца; сертификат должен соответствовать IP сервиса.
Запросите у владельца публичный сертификат и проверьте адрес.
Не отключайте проверку TLS и не пересылайте приватный TLS-ключ.

## Вопрос не имеет подтверждённого ответа

Справка не содержит всех возможных причин. Если в тикете нет кода ошибки,
адреса, номера дня или шага воспроизведения, поддержка должна уточнить данные.
Типовая причина не становится установленным диагнозом без подтверждения.
