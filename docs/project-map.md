# Карта AI Challenge

AI Challenge — репозиторий учебных приложений. Каждое задание находится в
папке `day-NN`; инструкция установки и запуска — в README соответствующего дня.
Это несколько приложений, а не один сервер, обслуживающий все дни.

## Этапы обучения

- Дни 01–06: запросы к языковой модели, параметры и первый агент. Веб-сервер Flask.
- Дни 07–12: FastAPI, Vue/Vite, SQLite, история, стратегии контекста, память и профили.
- Дни 13–15: состояние задачи, checkpoint, инварианты и контролируемые переходы.
- Дни 16–20: MCP, инструменты погоды, календаря, поиска и фоновые задачи.
- Дни 21–25: индексация README, RAG-поиск, фильтрация, цитаты и память задачи.
- Дни 26–30: Ollama, локальная Qwen, чат, локальный RAG, параметры и HTTPS-сервис.
- День 31: ассистент разработчика по README и docs с Git-контекстом через MCP.
- День 32: автоматическое ревью PR по diff, документации и коду.
- День 33: поддержка пользователей по справке и вымышленным тикетам через MCP.

## Где искать код

В большинстве поздних дней `backend/` содержит Python API и логику агента,
`frontend/src/` — Vue-интерфейс, `tests/` — backend-тесты,
`frontend/tests/` — frontend-тесты, `scripts/` — запуск и служебные команды.
Ранние Flask-дни устроены иначе: точная структура указана в их README.

`packages/assistant_core/` — общая устанавливаемая RAG-библиотека новой недели.
Day31 и Day33 имеют собственные индексы; индекс Day32 строится для конкретного
снимка PR. `docs/` — публичная документация проекта. `docs/support/` — справка
поддержки, которая служит отдельным корпусом Day33.

## Git и текущая ветка

Документация не может достоверно назвать текущую Git-ветку: она меняется во
время работы. Day31 получает ветку и SHA через настоящий MCP-инструмент.
При detached HEAD корректный результат — отсутствие имени ветки и SHA коммита.
