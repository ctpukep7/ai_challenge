# Запуск приложений

## Как выбрать инструкцию

Каждый день запускается из своей папки. Откройте `day-NN/README.md` и установите
именно перечисленные там зависимости. Команда из другого дня может использовать
другой порт, базу или окружение.

Ранние дни используют Flask. У многих поздних дней `npm run dev` запускает
FastAPI и Vite. `npm run build` собирает frontend; production-запуск описан
в README дня. Общего корневого `npm run dev` для всех приложений нет.

## Облачная и локальная модели

Для DeepSeek нужен собственный API-ключ на backend и доступ в сеть.
Ключ не вводится в исходники и не отправляется браузеру.

Для локальных Day26–30 нужен работающий Ollama с установленной моделью.
Day30 обращается к Ollama по `http://127.0.0.1:11434`; клиентские устройства
подключаются к HTTPS-шлюзу Day30, а не напрямую к Ollama.

Новая неделя Day31–33 использует DeepSeek и локальные эмбеддинги.
Установка новых весов локальной LLM не требуется.

## Если приложение не открывается

Проверьте, запущен ли процесс, правильны ли адрес и порт, завершена ли установка
и production build. Ошибка занятого порта не требует завершать неизвестный
процесс: сначала определите, какое приложение его использует.
Точная команда запуска и адрес всегда берутся из README выбранного дня.
