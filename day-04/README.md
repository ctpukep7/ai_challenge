# Day 04 — Машина температуры

Flask-приложение отправляет один и тот же промпт шесть раз — с `temperature = 0`, `0.7`, `1.2`, `1.5`, `1.7` и `1.9` — и показывает результаты рядом. Все шесть запросов стартуют одновременно; карточки заполняются независимо по мере прихода ответов. По умолчанию используется `deepseek-v4-flash`, но в sidebar можно выбрать OpenRouter и бесплатную модель.

Во всех шести запросах одинаковы модель, сообщения и все настройки sidebar. `max_tokens` по умолчанию **не передаётся**: у эксперимента нет искусственного ограничения длины. Единственное автоматически меняющееся поле — температура.

## Как провести эксперимент

1. Введите свой текст либо нажмите **«Демо-промпт»**.
2. Нажмите **«Запустить эксперимент»**. Шесть запросов стартуют одновременно, а карточки ниже заполняются независимо по мере готовности.
3. При необходимости задайте общий формат, `max_tokens`, до 16 stop sequence, thinking mode, провайдера или модель. Пустые поля не добавляются в API-запрос.
4. Откройте `i` в каждой карточке и убедитесь, что JSON-запросы отличаются только полем `temperature`.
5. Ответы поддерживают Markdown: заголовки, списки, выделение и блоки кода отображаются как разметка.
6. Под карточками таблица покажет время, выходные токены и причину завершения каждого запуска.

Тёмная панель справа содержит настройки из Day 03, кроме переключателей методов: формат, лимит, thinking, stop sequence, провайдер и модель. Эти настройки применяются одинаково ко всем шести вызовам.

> Для чистого сравнения температур выберите фиксированную модель `deepseek-v4-flash`. Режим OpenRouter Free Router может направить разные вызовы к разным бесплатным моделям и исказить результат. Один запуск приложения делает шесть API-вызовов.

## Как интерпретировать результат

| Температура | Обычно подходит для |
| --- | --- |
| `0` | Фактов, расчётов, кода, извлечения данных и повторяемых инструкций. |
| `0.7` | Объяснений, аналитики, диалога и текстов, где нужен баланс ясности и вариативности. |
| `1.2` | Мозгового штурма, заголовков, сюжетов, рекламных вариантов и других творческих задач. |
| `1.5` | Смелых вариантов и творческих черновиков; результат требует внимательной проверки. |
| `1.7` | Поиска неожиданных направлений, если факты затем проверяет человек. |
| `1.9` | Максимально свободного брейншторма; не для готовых фактических ответов. |

Это не правило «чем выше, тем хуже точность». Проверять факты и расчёты нужно при любом значении температуры.

## Демо-промпт

```text
Кратко, в 6–8 коротких предложениях, объясни, почему на мокрой дороге автомобилю требуется больше расстояния для торможения.

Обязательно упомяни сцепление шин с дорогой, скорость и тормозной путь.
Структурируй ответ так:
1. объяснение причины;
2. один бытовой пример;
3. список из ровно 2 разных метафор;
4. короткий вывод.
```

Он удобен для сравнения: точность — это корректная связь сцепления, скорости и тормозного пути; креативность — образность метафор; разнообразие — насколько две метафоры и формулировки отличаются внутри карточки и между температурами.

## Запуск

Нужны Python 3.10+ и ключ хотя бы одного провайдера. Для режима по умолчанию нужен DeepSeek; для OpenRouter — отдельный ключ.

```bash
cd day-04
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Добавьте DEEPSEEK_API_KEY в .env
# Необязательно: добавьте OPENROUTER_API_KEY для режима OpenRouter
python3 app.py
```

Откройте [http://127.0.0.1:5003](http://127.0.0.1:5003).

## Проверка

```bash
cd day-04
.venv/bin/python -m unittest -v
```

`.env` и виртуальное окружение игнорируются Git. API-ключ не попадает в браузер и не показывается в JSON-превью.
