# AI Challenge 9

Этот репозиторий предназначен для хранения домашних заданий курса AI Challenge 9.

Каждое задание находится в отдельной папке и сопровождается инструкцией по запуску.

## Неделя: память и управляемое состояние

| День | Главная учебная цель |
| --- | --- |
| [11](day-11/README.md) | Разделить short-term, working и long-term память и явно выбирать слой записи |
| [12](day-12/README.md) | Автоматически применять структурированный профиль пользователя к каждому запросу |
| [13](day-13/README.md) | Сохранять phase, checkpoint и точно продолжать задачу после паузы |
| [14](day-14/README.md) | Хранить инварианты отдельно и детерминированно отклонять конфликтующие решения |
| [15](day-15/README.md) | Разрешать переходы только по графу и после выполнения проверяемых prerequisites |

Демо-кнопки во всех этих стендах только заполняют поля. Сохранение, отправка,
утверждение и переход выполняются отдельными явными действиями пользователя.

## Оркестрация MCP

[День 20](day-20/README.md): агент сам выбирает инструменты трёх MCP-серверов
для поездки по погоде и личному календарю. Интерфейс показывает трассу и
проверенный проект; событие создаётся после подтверждения карточки.
Запуск из `day-20`: `npm run dev` (API 5019, frontend 5186).

## Неделя RAG

### День 21 — индексация документов

[Day 21](day-21/README.md) индексирует README текущего проекта: корневой файл
и README дней 1–20. Markdown разбивается двумя стратегиями — фиксированные
окна и разделы по заголовкам. Для каждого чанка создаётся локальный эмбеддинг
с метаданными `source`, `title`, `section` и `chunk_id`; индекс сохраняется в SQLite.
Интерфейс показывает источники, этапы сборки, сравнение стратегий и поиск
по сохранённым векторам. README самих RAG-дней исключены из корпуса.

Для демонстрации первого прогона кнопка **«Начать показ»** создаёт отдельный
пустой demo-индекс, показывает 0 чанков и затем проводит через разбиение,
генерацию эмбеддингов и запись в SQLite. Основной индекс остаётся на месте.
Установка и запуск описаны в [README дня 21](day-21/README.md); интерфейс
доступен на `http://127.0.0.1:5187/` после запуска из `day-21` команды
`npm run dev`.

### День 22 — первый RAG-запрос

[Day 22](day-22/README.md) использует тот же README-корпус и алгоритм поиска Day 21:
вопрос кодируется вектором, из собственного SQLite выбираются релевантные чанки,
после чего одна модель отвечает дважды — без контекста и с найденными
фрагментами. Интерфейс показывает оба ответа, реальные источники и точные
запросы к модели. Десять контрольных вопросов имеют заранее записанные
ожидаемые факты и README-разделы; сравнение качества помечено как эвристическое.
Запуск из `day-22`: `npm run dev` (API 5021, frontend 5188).

### День 23 — фильтрация релевантности и query rewrite

[Day 23](day-23/README.md) сравнивает три варианта RAG по тому же
корпусу README текущего репозитория: обычный поиск, фильтрацию
по cosine-порогу и переписывание запроса с фильтрацией. Порог и top-K до/после
отбора меняются в интерфейсе. Для каждого кандидата видны оценка, источник
и причина отсечения; в запрос к модели попадают только выбранные фрагменты.
Если фильтр оставляет пустой контекст, стенд явно сообщает о недостатке данных.

Локальный rewrite раскрывает сокращения и нормализует термины; вариант через
DeepSeek формирует отдельный поисковый запрос. Исходный вопрос для ответа
сохраняется. Контрольный прогон включает вопросы по README и посторонние
запросы; он сравнивает поиск отдельно от генерации ответов и экспортирует
результаты в JSON. Запуск из `day-23`: `npm run dev` (API 5022, frontend 5189).

### День 24 — цитаты, источники и антигаллюцинации

[Day 24](day-24/README.md) возвращает ответ с источниками и дословными цитатами
из найденных чанков. Сервер проверяет цитаты, а отдельный вызов DeepSeek —
поддержку утверждений контекстом. При слабом контексте или отсутствии
подтверждений ассистент отвечает «Не знаю» и просит уточнить вопрос.
Десять контрольных вопросов проверяют источники, цитаты и смысл ответа.
Запуск из `day-24`: `npm run dev` (API 5023, frontend 5190).

### День 25 — мини-чат с RAG и памятью задачи

[Day 25](day-25/README.md) сохраняет диалоги в SQLite, заново ищет контекст
для каждого вопроса и показывает проверенные источники. Цель, уточнения,
ограничения и термины собираются автоматически по мере беседы.
Два сценария по 15 вопросов проходятся вручную: подставить следующий вопрос,
при желании изменить и отправить. История и память сохраняются после перезапуска.
Запуск из `day-25`: `npm run dev` (API 5024, frontend 5191).
