# AI Challenge 9

Учебные приложения курса AI Challenge 9: от первого запроса к языковой модели
до агентов с памятью, MCP-инструментами, RAG и самостоятельного macOS-приложения.
Каждый день находится в отдельной папке `day-NN` со своим README.

## Pipeline · дни 31–35

- [День 31 — ассистент разработчика](day-31/README.md): ответы по README и документации через RAG, `/help`, Git-контекст и инструменты чтения через MCP.
- [День 32 — автоматическое AI-ревью PR](day-32/README.md): CLI и GitHub Action анализируют diff с RAG-контекстом, публикуют inline-комментарии и сводки по SHA.
- [День 33 — ассистент поддержки](day-33/README.md): ответы по отдельной справке AI Challenge и вымышленным тикетам через MCP.
- [День 34 — ассистент работы с файлами](day-34/README.md): поиск и чтение кода, подготовка Markdown, просмотр diff и сохранение после подтверждения.
- [День 35 — рабочее время из истории AI](day-35/README.md): отдельное macOS-приложение на Tauri, Vue и Python; история Codex, Git и CalDAV, разбор задач и подтверждённая отправка времени в solidtime. Исходники Day35 пока локальные.

## Запуск

1. Откройте README нужного дня.
2. Установите указанные там Python- и frontend-зависимости.
3. Настройте провайдера модели и выполните команды запуска из README дня.

У приложений отдельные порты, базы и настройки. Часть поздних дней использует
окружения или модули предыдущих заданий; копии одной папки может быть недостаточно.
Общей команды запуска всех дней нет. API-ключи задаются локально по инструкции
дня; в Day35 они хранятся в macOS Keychain.
