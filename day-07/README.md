# Day 07 — Сохранение контекста

`AssistantAgent` сохраняет переписку в SQLite и после перезапуска FastAPI продолжает диалог с тем же контекстом.

```text
Vue + Vite → FastAPI → AssistantAgent → SQLite (история) → LLM → SQLite (новая пара сообщений) → Vue
```

## Что сохраняется

Файл `data/context.sqlite3` содержит сессии и упорядоченные сообщения `user` / `assistant`. Перед каждым запросом агент сам загружает историю выбранной сессии, добавляет новый вопрос и отправляет весь диалог модели. После успешного ответа он сохраняет вопрос, ответ и безопасное JSON-превью запроса.

SQLite — источник истины: браузер не хранит сообщения в `localStorage`. Поэтому после остановки и повторного запуска приложения список чатов и их контекст остаются прежними.

## Интерфейс

- В левом сайдбаре можно создать новую сессию. Меню `⋯` у каждой сессии позволяет её переименовать или удалить вместе со всей историей.
- Настройки следующего ответа открываются по кнопке «⚙ Настройки»: провайдер, модель, формат, temperature, max tokens, thinking mode и до 16 stop sequences.
- Обычный `Enter` отправляет вопрос; `Shift+Enter` или `⌘+Enter` добавляет перенос строки.
- Кнопка «ⓘ JSON-запрос» у ответа показывает безопасное превью фактически отправленного запроса без API-ключа.

## Проверка задания

1. Откройте приложение и задайте агенту факт о себе, например: «Меня зовут Андрей. Запомни это».
2. Остановите приложение `Ctrl+C`.
3. Запустите его снова и откройте ту же сессию.
4. Спросите: «Как меня зовут?» — агент получит первое сообщение из SQLite вместе с новым вопросом.

## Запуск

```bash
cd day-07
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm install
npm --prefix frontend install
cp .env.example .env
npm run dev
```

Добавьте `DEEPSEEK_API_KEY` в `.env`, затем откройте http://127.0.0.1:5173.

`npm run dev` запускает два независимых процесса: Vue-интерфейс на `5173` и Python API на `5006`. Vite перенаправляет запросы `/api` к FastAPI, поэтому API-ключ остаётся только на Python-стороне. Документация API доступна по адресу http://127.0.0.1:5006/docs.

```bash
npm run build
npm test
```

## Структура

```text
backend/         FastAPI, AssistantAgent и SQLite-хранилище
frontend/        Vue + Vite интерфейс
data/            локальная SQLite-база (игнорируется Git)
.env             API-ключи (игнорируется Git)
```

Vue отвечает только за интерфейс и вызовы локального API. Логика агента, вызов LLM и сохранение контекста остаются в Python-файлах `backend/agent.py` и `backend/store.py`.

`.env`, SQLite-база, `node_modules`, виртуальное окружение и видео не попадают в Git.

## Восстановление памяти и настройки Day 07

В Day 07 постоянная память означает повторную загрузку сообщений из SQLite перед каждым запросом. Модель не обучается на переписке и не получает отдельную долговременную память: контекст состоит из всей истории выбранной сессии, нового вопроса и необязательной system-инструкции текущего формата/stop sequences. Разные сессии имеют отдельные истории. Смена провайдера или модели в той же сессии сохраняет эту историю и передаёт её новому выбранному провайдеру.

В Day 07 пара user/assistant записывается одной транзакцией только после непустого успешного ответа. Ошибка API не добавляет вопрос в сохранённую историю. JSON-превью записано у assistant-сообщения; названия сессий также хранятся в базе. Первое успешное сообщение автоматически заменяет «Новый диалог» заголовком из первых 34 символов вопроса. Ручное название допускает до 80 символов. При удалении сессии каскадно удаляются её сообщения, а после удаления последней создаётся новый пустой диалог.

В Day 07 SQLite сохраняет тексты сообщений и JSON запроса, но не отдельные метрики usage или настройки следующего ответа. Настройки Vue живут в памяти страницы и после её перезагрузки возвращаются к исходным: DeepSeek, `deepseek-v4-flash`, temperature 0, thinking disabled, пустые формат, max_tokens и stop sequences. Сервер допускает temperature 0–2, max_tokens 1–10000 и до 16 непустых уникальных stop-маркеров; для OpenRouter исходная модель — `openrouter/free`. При thinking enabled для DeepSeek temperature не передаётся.

В Day 07 `POST /api/ask` получает `conversation_id`, `prompt` и `controls`. Неправильный ввод даёт HTTP 400, отсутствие ключа — 503, ошибка/пустой ответ провайдера — 502. Длинная история передаётся целиком: автоматического сжатия, окна и предварительного подсчёта токенов нет, поэтому лимит контекста может отклонить сам провайдер. Проверка задания демонстрирует наличие факта в запросе после перезапуска; точность воспроизведения факта всё ещё зависит от модели.
