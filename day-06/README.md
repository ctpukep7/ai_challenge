# Day 06 — Первый агент

Минимальный веб-чат с отдельной сущностью `AssistantAgent`. Пользователь пишет вопрос в браузере, Flask передаёт его агенту, а агент самостоятельно создаёт запрос к DeepSeek и возвращает финальный текст.

## Чем это отличается от Day 01

В Day 01 маршрут Flask напрямую вызывает API: читает ключ, создаёт `OpenAI`, формирует `messages`, запрашивает модель и извлекает текст из ответа. Это удобно для первого API-вызова, но весь HTTP-код и логика LLM находятся в одной функции.

В Day 06 маршрут `/ask` отвечает только за HTTP: он принимает JSON и вызывает `agent.reply(prompt)`. Вся LLM-логика скрыта в классе `AssistantAgent` в [agent.py](agent.py):

```text
Браузер → Flask /ask → AssistantAgent → DeepSeek API → ответ в браузере
```

Если настройки формата и stop-маркеры пусты, агент нейтральный: он передаёт модели только текст пользователя, без system prompt, истории, памяти или инструментов.

### Что именно делает агент

`AssistantAgent` выбирает провайдера и модель из настроек, берёт URL из описания провайдера и читает ключ из окружения перед вызовом. Класс хранит фабрику клиента и необязательный готовый клиент для тестов. Метод `reply(prompt)`:

1. Убирает лишние пробелы и отклоняет пустой текст.
2. Сам проверяет ключ выбранного провайдера и создаёт `OpenAI`-клиент для вызова, если тестовый клиент не передан извне.
3. Отправляет в модель одно user-сообщение и, при заданных формате или stop sequences, добавляет system-инструкцию.
4. Проверяет, что модель вернула непустой текст, и возвращает готовый ответ.
5. Преобразует проблемы конфигурации и API в отдельные ошибки, понятные интерфейсу.

В [app.py](app.py) Flask не импортирует `OpenAI` и не знает деталей DeepSeek. Он лишь валидирует HTTP-ввод, делегирует работу `AssistantAgent` и превращает результат или ошибку в JSON-ответ. Поэтому позже агента можно расширять — например, добавить историю или инструменты — не переписывая интерфейс и маршрут `/ask`.

## Настройки и метрики

В боковой панели доступны настройки из предыдущих дней: провайдер (DeepSeek или OpenRouter), модель, текстовая инструкция формата, `temperature`, необязательный `max_tokens`, до 16 stop sequence и thinking mode для DeepSeek. При включённом thinking `temperature` не передаётся DeepSeek, потому что этот параметр в таком режиме не влияет на результат.

После ответа агент показывает время, входные и выходные токены, reasoning-токены, причину завершения, применённый thinking mode, провайдера, фактически выбранную модель и оценочную стоимость. Блок JSON показывает фактически отправленный запрос без API-ключа. Markdown в ответе отображается безопасно.

## Подготовка и запуск

Нужны Python 3.10+ и ключ выбранного провайдера; для DeepSeek он создаётся в [DeepSeek Platform](https://platform.deepseek.com/api_keys).

```bash
cd day-06
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Добавьте ключ в `.env`:

```text
DEEPSEEK_API_KEY=ваш_ключ_DeepSeek
# Необязательно для OpenRouter:
OPENROUTER_API_KEY=ваш_ключ_OpenRouter
```

```bash
python3 app.py
```

Откройте [http://127.0.0.1:5005](http://127.0.0.1:5005).

## Контракт запроса и границы Day 06

В Day 06 браузер отправляет `POST /ask` с `prompt` и необязательным объектом `controls`. По умолчанию выбраны DeepSeek, `deepseek-v4-flash`, `temperature = 0`, thinking выключен, формат и stop sequences пусты, `max_tokens` не задан. Для OpenRouter модель по умолчанию — `openrouter/free`. Сервер принимает temperature от 0 до 2 и max_tokens от 1 до 10000; пустое поле max_tokens означает, что параметр вообще не отправляется. Пустые stop-маркеры убираются, повторяющиеся объединяются, остаётся не больше 16. Название модели ограничено 200 символами.

Day 06 выполняет один вызов Chat Completions на вопрос. Класс агента здесь организует запрос, проверку результата и метрики; самостоятельного планирования или цикла инструментов нет. Список сообщений на экране не входит в следующий запрос: ни SQLite, ни передача предыдущей переписки в этой реализации не предусмотрены. Для проверки границы памяти можно сообщить факт первым запросом и посмотреть JSON второго: первого сообщения в нём не будет.

Day 06 возвращает HTTP 400 для пустого вопроса или некорректных настроек, 503 при отсутствии ключа и 502 при ошибке провайдера, пустом или неожиданном ответе. Стоимость является оценкой по встроенной таблице для известных DeepSeek-моделей и требует cache-hit, cache-miss и completion usage; при отсутствии этих данных цена неизвестна. Для выбранных OpenRouter-моделей с суффиксом `:free` оценка равна нулю. Это не подтверждение актуального тарифа провайдера.
