# Day33 — краткий справочник HTTP API поддержки

Источники: `day-33/backend/app.py` (маршруты и коды ошибок), `day-34/generated/qa-multi-api.md` (прежняя расширенная версия).

## Эндпоинты

1. `GET /api/tickets` — список учебных тикетов через MCP `list_tickets()`; ответ `{tickets, trace}`; при сбое MCP — 503.
2. `GET /api/index` — статус локального индекса справки (`ready`, `stale`, `documents`, `chunks`); при сбое индекса или embedding-модели — 503.
3. `POST /api/index/build` — атомарная пересборка индекса под общим `asyncio.Lock`; занятый lock — 409, ошибка сборки — 503.
4. `POST /api/support/ask` — ответ по выбранному тикету с цитатами из справки; тело `AskRequest` (`ticket_id`, `question`, `history` до 8 элементов, история только по тому же тикету).

## Общее поведение

- Один запрос генерации или индексации одновременно: иначе 409 `Запрос уже выполняется`.
- Ошибки — `HTTPException(status, detail)` с русским текстом; интерфейс показывает `detail`.
- Коды `ask`: 404 `Неизвестный тикет`, 409 (индекс не построен / устарел), 422 (схема, история, пустой вопрос), 502 (сбой провайдера), 503 (MCP, поиск, кэш модели).
- MCP read-only: тикеты и пользователи только читаются, секреты не запрашиваются.
